
# 🧪 Pruebas del programa (Tests)

Esta carpeta está destinada a almacenar las pruebas automatizadas que permitirán verificar el correcto funcionamiento de los diferentes módulos del programa de análisis de secuencias de ADN.

## 🎯 Objetivos

- Comprobar que las funciones de Python producen resultados correctos.
- Detectar posibles errores en el procesamiento de secuencias.
- Verificar que los módulos funcionan correctamente después de realizar modificaciones.
- Facilitar el mantenimiento y la fiabilidad del programa.

## 🔬 Pruebas previstas

- **test_sequence_validation.py:** validación de secuencias de ADN y detección de caracteres no permitidos.
- **test_sequence_analysis.py:** comprobación del recuento de nucleótidos, longitud y contenido GC.
- **test_sequence_complement.py:** verificación de las secuencias complementarias y reverso-complementarias.
- **test_orf_detection.py:** comprobación de la identificación de posibles marcos abiertos de lectura.
- **test_sequence_translation.py:** verificación de la traducción de ADN a aminoácidos.
- **test_report_generator.py:** comprobación de la generación de informes.

## 🛠️ Herramientas previstas

Se contempla utilizar **pytest**, un framework de Python que permite crear y ejecutar pruebas automatizadas.

## 🚧 Estado actual

Las pruebas descritas están previstas para futuras fases de desarrollo. Actualmente no están implementadas, ya que el proyecto se encuentra en fase de planificación.
