# Análisis de secuencias de ADN
Descripción del proyecto

Este proyecto tiene como objetivo desarrollar una herramienta bioinformática en Python para el análisis automatizado de secuencias de ADN.

La aplicación permitirá introducir una secuencia de nucleótidos y realizar diferentes operaciones, como el cálculo de su longitud, el análisis de su composición nucleotídica, la determinación del porcentaje de GC y la obtención de secuencias complementarias.

Además, se contempla incorporar funcionalidades más avanzadas, como la identificación de marcos abiertos de lectura (ORF), la traducción de secuencias codificantes a aminoácidos y la comparación con secuencias disponibles en bases de datos biológicas.

Estructura del repositorio

data/: almacenamiento de las secuencias de ADN utilizadas como datos de entrada.

src/: código fuente de la aplicación desarrollada en Python.

results/: almacenamiento de los resultados generados por los análisis.

docs/: documentación técnica y metodológica del proyecto.

.gitignore: configuración de archivos y directorios excluidos del control de versiones.

LICENSE: condiciones de uso y distribución del proyecto.

Estado del proyecto

El proyecto se encuentra en fase de planificación y organización. El repositorio se ha creado como parte de una actividad grupal de la asignatura Introducción a la Programación Científica, del Máster Universitario en Bioinformática de la UNIR, con el objetivo de practicar la gestión de repositorios y el control de versiones mediante Git y GitHub.
