# Historial de versiones

## v0.4.0 — Revisión de la documentación

- Ampliación del README principal.
- Incorporación de los README de las carpetas src/, data/, results/ y test/.
- Documentación del flujo previsto del programa principal.
- Aclaración de las funciones previstas de los módulos de secuencias complementarias y calidad básica.
- Corrección de nombres de archivos y del formato de los comentarios en Python y R.
- Descripción de las entradas, salidas y el intercambio previsto de resultados entre Python y R.

## v0.3.0 — Planificación de los análisis en R

- Incorporación de archivos para estadísticas de contenido GC, comparación de secuencias, calidad básica, visualización e informes.
- Descripción inicial de sus funciones previstas.

## v0.2.0 — Planificación de los módulos Python

- Incorporación de archivos para validación, análisis básico, detección de ORF, traducción, búsquedas mediante BLAST y generación de informes.
- Descripción inicial de sus funciones previstas.

## v0.1.0 — Estructura inicial

- Creación del repositorio y de su estructura de carpetas.
- Incorporación del README inicial y de la licencia MIT.

## Estado del desarrollo

Las versiones descritas corresponden a la organización y documentación
del proyecto. Los módulos de análisis y las pruebas automatizadas están
pendientes de implementación.
