# Documentación del proyecto

## 1. Introducción

Esta carpeta contiene la documentación técnica y metodológica del proyecto **Análisis de Secuencias de ADN**, cuyo objetivo es desarrollar una herramienta bioinformática para el análisis, identificación y anotación biológica de secuencias de ADN.

## 2. Contenido de la documentación

La documentación se organiza en los siguientes apartados:

- **Descripción del programa:** funcionalidades principales, módulos y estructura del proyecto.
- **Metodología de análisis:** procedimientos utilizados para la validación, caracterización y análisis de secuencias de ADN.
- **Análisis evolutivo y filogenético:** metodología para el alineamiento múltiple, análisis de conservación y reconstrucción de árboles filogenéticos.
- **Herramientas y dependencias:** descripción de las bibliotecas, programas y recursos bioinformáticos utilizados.
- **Instalación y ejecución:** requisitos técnicos e instrucciones para instalar y utilizar el programa.
- **Ampliaciones futuras:** posibles mejoras y nuevas funcionalidades que se incorporarán al proyecto.

## 3. Organización de los documentos

Los documentos incluidos en esta carpeta son:

| Archivo | Descripción |
|---|---|
| `metodologia.md` | Descripción de los procedimientos y metodologías empleados en el análisis de secuencias de ADN. |
| `phylogenetics.md` | Descripción de las etapas del análisis evolutivo y filogenético. |

## 4. Estado del proyecto

El proyecto se encuentra actualmente en fase de desarrollo y organización. La documentación se actualizará progresivamente conforme se implementen y validen las diferentes funcionalidades del programa.
