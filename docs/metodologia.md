# Documentación

Esta carpeta contendrá la documentación técnica y metodológica del proyecto analisis-secuencias-adn.

La documentación prevista incluirá:

- Descripción de las funcionalidades del programa.
- Metodología de análisis de secuencias de ADN.
- Herramientas y bibliotecas bioinformáticas utilizadas.
- Instrucciones de instalación y utilización.
- Descripción de las posibles ampliaciones del proyecto.

Actualmente, el proyecto se encuentra en fase de planificación y organización del repositorio.
